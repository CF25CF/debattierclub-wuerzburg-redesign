# Debattierclub Würzburg — überarbeiteter Webauftritt

Ein schlankerer, moderner Entwurf für die Website des [Debattierclub Würzburg](https://www.debattierclub-wuerzburg.de/) (Colloquia Herbipolensia e.V.).

**Live:** https://cf25cf.github.io/debattierclub-wuerzburg-redesign/

Statische Seite — einfach `index.html` im Browser öffnen.

## Was wurde geändert

- Eine übersichtliche Startseite statt verstreuter Unterseiten
- Funktionierende Navigation (Anker + echte Links)
- Kürzere, lesbare Texte
- Klare Termin-Karten (Di + Do)
- Eigene, aufgeräumte Impressumsseite

## Struktur

```
index.html        Startseite
impressum.html    Impressum & Datenschutz
styles.css        Styles
images/           Fotos vom Original
```

Die Fotos stammen von der bestehenden Vereinsseite und gehören dem Verein.
